# employee-management-system-java

A simple console-based Java application to manage employee records.  
Built using **Object-Oriented Programming (OOP)** principles with clean class structure and user-friendly interaction.

## 🌟 Features

- ➕ Add new employees with ID, name, age, and salary
- ❌ Remove employees by ID
- 📋 Display all current employees
- 🚪 Exit the system gracefully
- ✅ Input validation and feedback messages

## 🧠 Core Concepts Used

- Java Classes and Objects
- Encapsulation with private fields and public getters/setters
- ArrayList for dynamic data storage
- Scanner for user input
- Control flow with loops and switch-case
